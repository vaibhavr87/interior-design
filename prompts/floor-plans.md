# Floor Plan & Diagram Prompts

Use `/diagram` in the Gemini CLI to generate architectural diagrams and floor plans.

## Floor Plans
```
/diagram Open-plan apartment floor plan, 60 sqm, living/dining/kitchen combined,
one bedroom, one bathroom, balcony. Clean architectural line drawing, top-down view.

/diagram Two-story house floor plan, 120 sqm per floor, 3 bedrooms, 2 bathrooms,
open kitchen-dining, home office, garage. Architectural blueprint style.
```

## Furniture Layout
```
/diagram Living room furniture layout for a 5m x 4m rectangular room.
Sofa facing TV wall, coffee table, two armchairs, bookshelf. Top-down view with dimensions.
```

## Mood Boards
```
/story Create a 4-panel interior design mood board for a Japandi-style bedroom:
panel 1 color palette, panel 2 materials and textures, panel 3 furniture pieces,
panel 4 finished room visualization.
```
