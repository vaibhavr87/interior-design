# Living Room Prompts

Use these with `/generate` or `/nanobanana` in the Gemini CLI.

## Modern Minimalist
```
/generate A modern minimalist living room with clean lines, neutral palette of whites and warm grays,
low-profile sofa, natural wood coffee table, and indirect lighting. Scandinavian influence.
--preview
```

## Cozy Bohemian
```
/generate A cozy bohemian living room with layered textiles, macrame wall art, mix of warm earthy tones,
rattan furniture, indoor plants, and eclectic decorative objects. Warm afternoon light.
--preview
```

## Mid-Century Modern
```
/generate A mid-century modern living room featuring tapered-leg furniture, geometric patterns,
teak wood accents, mustard yellow and olive green tones, and a sunburst clock. 1960s aesthetic.
--preview
```

## Edit an Existing Room Photo
```
/edit path/to/room.jpg Change the wall color to a deep navy blue and add warm Edison bulb lighting
--preview
```
